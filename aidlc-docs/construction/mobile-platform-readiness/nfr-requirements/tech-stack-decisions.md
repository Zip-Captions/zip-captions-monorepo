# Tech Stack Decisions: Unit 10, Mobile Platform Readiness

**Date**: 2026-10-25. No new package is added by this unit.

| Decision | Choice | Rationale |
|---|---|---|
| Speech engine | `PlatformSttEngine` over `speech_to_text` 7.3.0 (locked), iOS and Android only | Already in `zip_core`; Sherpa-ONNX needs a model download and belongs to the parked on-device multilingual unit (FD Q1 = A) |
| Recognition mode | `onDevice: true` via `SpeechListenOptions(onDevice: true, partialResults: true, cancelOnError: false)`, **plus** an `OnDeviceSupportChecker` run before every `listen()` | Phase 1 NFR-2.1 and the mobile Alex scenario. `onDevice: true` alone enforces nothing with the stock plugin (iOS replies `onDeviceError` without returning; Android falls back silently), so the app refuses unless the check passes (Amendment 02) |
| On-device support checker | `typedef OnDeviceSupportChecker = Future<bool> Function(String localeId)`, a **required** `PlatformSttEngine` constructor parameter; implemented by `MethodChannelOnDeviceSupportChecker` in `zip_captions` over a method channel (`app.zipcaptions/speech_support`, `isOnDeviceSupported`) with small Swift (iOS) and Kotlin (Android) runner code; `onDeviceCheckTimeout = 2 s` | Keeps `zip_core` free of platform code; no new package. iOS: `supportsOnDeviceRecognition` for the plugin's locale; Android: API 31+ and `isOnDeviceRecognitionAvailable`. A first-party plugin package was considered and not chosen |
| `androidIntentLookup` | Never set | With it the plugin builds the default recogniser regardless of `onDevice` |
| User-facing strings | British English, `.arb` source of truth (`flutter gen-l10n`), plus `NSSpeechRecognitionUsageDescription` | Matches `zip_broadcast/l10n/arb/app_en.arb` ("Behaviour", "Colour") |
| Plugin version | `speech_to_text` 7.3.0 stays pinned by the lock file; **nothing needs filing upstream**. Revisit when a release includes the fixes for upstream **#673** (iOS missing `return`, PR #674) and **#678** (Android stop→listen race, PR #679). PR #674 merged 2026-09-14T19:26Z and PR #679 merged 2026-09-22T15:16Z; the latest stable, 7.5.0, was published 2026-09-14T19:14Z (before #674) and still has the missing `return`; **both fixes are in the 7.6.0 betas (beta.4, 2026-09-25) but in no stable release**. Do not put a pre-release on the privacy-critical path (SECURITY-10); beta.4 also changes the iOS audio-session default (`preserveExistingAudioSession` true) and needs `speech_to_text_platform_interface` 2.5.0 | Error codes and `done`/`notListening` behaviour were read from this version; an upgrade re-verifies Amendment 01's code classes (R5). Facts verified 2026-10-25; the stay-on-7.3.0 recommendation is pending James Petersen's confirmation |
| **Upgrade path for the checker** | When a **stable** 7.6.0 ships, replace the runner method channels with the plugin's own `has_on_device_support` behind the same `OnDeviceSupportChecker` typedef, which removes our Swift and Kotlin code; re-verify R5 (error codes, `done` and `notListening` ordering, listener fields) and the audio-session default at the same time | `7.6.0-beta.4` adds that method (Android: `SDK_INT >= 31` and `isOnDeviceRecognitionAvailable`; iOS: takes a `localeId`), the same check as ours |
| Permissions plugin | `permission_handler` ^11.3.1 with `permission_handler_apple` 9.3.0; `PERMISSION_MICROPHONE=1` in the Podfile | G2 cause confirmed by an A/B on the Simulator |
| Android manifest | Explicit `RECORD_AUDIO` and a `RecognitionService` `<queries>` entry; no `INTERNET` | NFR Q1 = A; `INTERNET` is G4 (Unit 13) |
| App identity | `app.zipcaptions.captions` on Android and iOS, display name "Zip Captions"; Android namespace and `MainActivity.kt` move to match | NFR Q4 = C; the old IDs were never uploaded |
| Dependency declaration | **Preferred: a factory in `zip_core` that builds `PlatformSttEngine` with its own `SpeechToText()`**, so `speech_to_text` stays declared in one package; the alternative (declaring it in `zip_captions/pubspec.yaml`) is not preferred. NFR Design confirms | The throwaway import raised `depend_on_referenced_packages`; SECURITY-10; one declaration point for the plugin the design is pinned to (Opus review session, correction 3, pending James Petersen's confirmation) |
| Audio device service | New `MobileAudioDeviceService` in `zip_core`, overridden into `audioDeviceServiceProvider` on every platform | FD Q3 = A |
| Error channel | `SttErrorSource.setErrorListener(...)` and `SttEngineError` (kind only) in `zip_core` | Amendment 01 R1; `very_good_analysis` forbids a lone setter |
| PBT framework | Repo Dart-3 shim copied to `zip_captions/test/helpers/pbt.dart`; fixed seeds 0-99, no shrinking, no seed printed | NFR Q10 = C; the real `glados` is Dart-3-incompatible (accepted in earlier units) |
| Test doubles | Hand-written fakes for `SpeechToText`, `SttErrorSource`, `AudioDeviceService`; `mocktail` where it already exists | Matches earlier units |
| Signing | Policy only: no secrets in git; no signing change in this unit | NFR Q5 = A; Unit 11 implements |
| Host tooling note | `pod install` needs `LANG=en_US.UTF-8` on this host | Observed 2026-10-25 |
