## 2. Ground rules for Part 2

1. **TDD-first** within each group: the test step comes before the implementation step it guards, and is run to show it fails for the right reason before the implementation lands.
2. **Property tests** use the repo shim (`test/helpers/pbt.dart`: fixed seeds 0 to 99, no shrinking, no seed printed). A failing sequence must be reproducible from the fixed seed plus the printed command list.
3. **No transcript text in any log** on the new path (SECURITY-03): enum names, booleans or `e.runtimeType` only.
4. **Copy, never retype**, for verbatim file relocation: use `cp`/`mv` (the shim copy, the `MainActivity.kt` relocation).
5. **Do not register `PlatformSttEngine` outside the committed change.** No throwaway edits remain; `git status` is recorded at the start and end of Part 2.
6. Do not edit completed units or Phase 1 records. Evidence goes in this unit's `evidence/`.
7. Quality gate after each group: `dart analyze --fatal-infos` clean on the touched packages and the group's tests green.
